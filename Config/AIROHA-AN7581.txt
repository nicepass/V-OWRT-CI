#─────────────────────────────────────────────────────────────────────
# PON 光猫栈：必须显式开启，否则编出来的固件没有 PON 驱动，刷上去上不了网。
#
# 原因：这些包支持三态（y/m/n），kconfig 未指定时默认取 m。
#   =m  只编译成 .ipk，不装进 rootfs → manifest 里看不到
#   =y  编进 rootfs → 刷机后可用
# DEVICE_PACKAGES 里虽然引用了它们，但在 PER_DEVICE_ROOTFS + MULTI_PROFILE
# 组合下不足以把它们从 m 提升为 y，实测 2026-11-25 首次编译产物
# manifest 里 airoha-ponctl / airoha-pond / kmod-airoha-xpon 全部缺失，
# 而 pbs05 官方 configs/an7581.config 用 CONFIG_MODULE_DEFAULT_*=y 解决。
#
# 下面两组配套使用：
#   MODULE_DEFAULT  改默认值，覆盖所有未显式指定的引用方
#   PACKAGE=y       对 PON 应用本身再显式钉死
#─────────────────────────────────────────────────────────────────────

#PON 模块默认值（官方 configs/an7581.config 的做法）

CONFIG_MODULE_DEFAULT_kmod-airoha-xpon=y
